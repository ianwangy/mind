场景的"身份卡"。ID 作为 URL 参数,label 显示在界面顶部。

L1 输入框的默认模糊请求

Layer 1 · 环境感知卡

L1 顶部的 3 张 mock 环境卡(日历/最近屏幕/习惯)。contextForPrompt 是喂给 LLM 的精简版。

Layer 1 · 意图 Schema

最重要的字段。 你列 3-5 个 key,LLM 会按这些 key 组织它对用户意图的理解。 每个 value 是对 LLM 的字段约束(字数、格式、允许为空)。

Layer 2 · 坐标轴

两条"正交对立"的张力轴。例:"保守 / 激进"对立;"清晰 / 专业"不对立,别混。
给 LLM 的范例,LLM 会据此推断类似风格的轴
删减式塑造的初稿要覆盖哪些维度,用中文顿号分隔

Layer 3 · 编排参数

L3 生成计划的提示线索。步数别太多,流程是该领域的典型骨架动词。

Layer 3 · 协作冲突 (mock)

L3 侧栏展示两张冲突卡:机构规则 + 另一个 AI 子代理的建议。本场景若无冲突,institutionalRule 写"(本场景无机构规则冲突)"即可。
Sub-agent 建议接纳后新增的步骤

Layer 4 · 时间轴刻度

Gantt 总跨度和刻度间隔。短任务用小数字(如写邮件 3 天 / 1 天刻度),长任务用大的(如产品发布 30 天 / 5 天刻度)。
